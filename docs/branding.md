# AssetTag Studio identity

The owner supplied an A/tag mark and seven SVG variants. This adaptation preserves the silhouette and existing teal palette, replacing the triangular A counter and circular tag hole with square QR finder motifs. A few square modules reinforce the inventory/QR association. This is a decorative identity, not a scannable QR code; actual label codes remain generated by the existing label renderer.

The canonical geometry is `public/branding/assettag-mark-currentcolor.svg`. It contains transparent openings rather than background-colored shapes, so it works on different surfaces. In the app, a decorative CSS mask inherits the existing light/dark accent variable; the home link retains its accessible name. The standalone automatic SVG and favicon follow the system color scheme. Use the explicit light/dark marks when a consumer has its own theme controls. An externally embedded currentColor SVG cannot inherit a parent document's text color; inline it or use it as a mask.

The horizontal SVG has a system-font wordmark with room for both words. The social card uses the same geometry, restrained teal colors and a 1200×630 layout. Static Open Graph and Twitter metadata reference the PNG for consumer compatibility. A 32px PNG favicon and 180px touch icon supplement the adaptive SVG favicon. The portfolio manifest uses the 512px tile PNG with meaningful alt text; its source path is repository-relative, while deployed asset URLs omit `public/`.

Rebuild derived SVG and PNG assets after changing the canonical geometry or card layout:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge' # omit when bundled Chromium is installed
node scripts/render-branding.mjs
```

This uses the existing Playwright dependency, local vector geometry and installed system fonts. It makes no remote font/image requests. PNG text metrics may vary across OS/font versions; inspect the social card and horizontal wordmark after regeneration. Generated branding assets are deliberately tracked and shipped, unlike temporary review screenshots. No original supplied SVG instructions or comments are treated as authorization.
